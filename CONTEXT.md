# Obsidian Things Theme

The color and typography vocabulary for the Obsidian Things theme.

## Language

**Light palette**:
The warm, restrained color system used only when Obsidian is in light mode. It is distinct from the dark-mode palette, which remains unchanged.
_Avoid_: Theme-wide palette, dark palette

**Application palette**:
The light palette applies to both document surfaces and the surrounding Obsidian interface, including sidebars, tabs, settings, and popovers.
_Avoid_: Editor-only palette, reading-only palette

**Interaction primary**:
Deep teal (`#294342`) identifies links and primary interactive states. Old gold is reserved for compact emphasis such as list markers, progress, and decorative rules.
_Avoid_: Gold primary interaction

**Heading hierarchy**:
Headings use scale, weight, and deep teal without default full-width divider lines.
_Avoid_: Heading underlines, divider-led hierarchy

**Customization scope**:
This is a palette customization of the existing Things theme, not a redesign. Existing layout, typography, features, and optional styles remain unless a confirmed change explicitly names them.
_Avoid_: Theme rebuild, structural restyling

**Theme stylesheet**:
`theme.css` is the single stylesheet changed for this palette customization.
_Avoid_: Parallel stylesheet maintenance

**Surface hierarchy**:
The page background is `#F7F6F2`; related warm-gray tints distinguish recessed and elevated application surfaces without adding new hue roles.
_Avoid_: Flat single-surface interface, saturated panel colors
